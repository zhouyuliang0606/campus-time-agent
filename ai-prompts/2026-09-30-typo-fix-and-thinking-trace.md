# 2026-09-30 修错别字 + 展示思考过程

## 一、用户 Prompt（原话）

> @image#1:Clipboard_Screenshot.png，没有展示思考过程，没有修改错别字

（截图内容：学生在对话框里打的是 **「中文12点的车」**——「中文」是「中午」的笔误；
管家回的卡片标题是 **「中文的车」**，错别字一字未改，而且「12点」也整段丢了。）

用户这句话只有两条，但**每一条都是一整类问题**：

| 用户说的 | 真正要解决的 |
|---|---|
| 没有修改错别字 | 打错的字要**按最可能的意思理解**，而且各种打错方式都得能理解 |
| 没有展示思考过程 | 结果不对时学生要能**自己看出是哪一步错了** |

## 二、AI 研判：先把「为什么会长出『中文的车』」查到底

没有直接照着截图改，而是先给这三层各写一个最小复现（用真机 + 打桩两种跑法）：

| 层 | 问题 | 复现 |
|---|---|---|
| ① **样本库**（最严重） | 模糊匹配**命中就把整条字段抄走** | 「我想去健身，帮我安排个时间」撞「…游泳…」(0.73) → 卡片写「游泳」；「…练会儿钢琴」撞「…练会儿吉他」(0.82) → 「练吉他」 |
| ② **规范话** | `to_canonical` 只拼 `start and end` | 模型读懂了 `start=12:00`、`end` 空 → 整段钟点被丢掉 → bits 空 → 退回原话 |
| ③ **规则层** | `_normalize_clock` 只认"读音对、写法对"的口语 | 「中文」不是时间词、擦标题擦不掉 → 整串留在标题里 |

第 ① 层是**最严重**的：学生说健身、系统回游泳，而且轨迹里写着"样本库命中"，
看起来还挺有道理，**根本看不出错在哪**。这类错比"没听懂"坏得多。

顺带确认了一件事：**模型自己其实会纠错别字**（实测「下午三点的会义」→ title「开会」），
但**不稳定**——「中文12点的车」它给 title「12点的车」，换个说法又问成 chat。
所以不能只靠"它大概会"，规则层得有一条确定性兜底（离线演示也不能把错字写进日程）。

## 四、三道闸门：纠错别字为什么不能只写一行

第一版写完就被自己的测试打回来了三次，每次都是"纠错"变成了"改坏"：

| 闸门 | 不拦会怎样（实测） |
|---|---|
| ① 位置上本来就是时间词的，原样收下 | **连环改**：「今田晚上有课」→「今夜里上午课」（今天/今晚/今夜互相都只差一个字） |
| ② `_NOT_TIME_WORDS` + 星期几不许动 | **悄悄少一个词**：「上班」和「上午」只差一个字，「加个上班打卡」被纠成「上午」再擦掉 → 变成「打卡」 |
| ③ 必须处在时间语境（后面紧跟钟点/星期） | 没有语境也敢猜：「明夭交电费」会被"修" |

取向是**宁可漏纠**：没钟点的笔误（「明夭交电费」）这儿不纠，留给语义层；
这条兜底只为"没配 key 的离线演示也别把错字写进日程"。

## 六、自踩自修（诚实记录）

1. **D 批假红：一句明白的"办事"被我说成"问事"。** 常规下单句（「帮我加个游泳周四19:00」）
   是**故意不叫**语义层的（零 API 调用），只看 `_sem_intent` 就会误报。
   改成 `intent = sem_intent or rule_hit` —— 轨迹里写假话比不写更坏。
2. **D 批假红（第二次）：问答分支被假 LLM 抢走。** 打桩返回的意图 JSON 被当成了答案本身。
   改成问答那条用 `with_key=False` 跑。
3. **反向验证抓出我自己写的弱断言。** A1/A4 一开始直接调 `fix()`，把
   `_normalize_clock` 里的接线拔掉它们**照样绿**——等于没测到真实链路。
   改成走 `_normalize_clock`，之后拔线立刻 A1~A4 全红。
4. **误删学生真实会话（最严重的一次）。** 清理测试残留时按"两条消息"这个特征筛，
   误删了 2 个真会话——其中 `se2cb0626e0` **正是截图里那个学生的**
   （「明天不上课了，明天回家」+「中文12点的车」）。已从备份全部还原（sessions.json 165 → 167）。
   教训：**清理演示数据不能按"长得像测试数据"筛，要按自己造的 id 精确删。**
5. **`_strip_title_noise` 的 docstring 第一行被我编辑时误删**，下一轮补回。
6. **测试文件里的引号用错**（ASCII `"` 嵌在 `"…"` 里）→ `SyntaxError`，
   全部改成「」，共 8 处。同一批还踩了 `Checker.check()` 只收 3 个位置参数，
   加本地 `_c()` 包装时手一抖把 `_c` 自己的调用也替换了（无限递归）。

## 七、顺带发现：学生的会话"教会"了系统

修好之后，学生自己的那句话被样本库学进去了（`intent_samples.json`，运行时数据、已 gitignore）：

```
09-30 13:05 add_todo  中文12点的车   title='坐车'   hits=3
09-30 12:56 add_todo  下午三点的会义  title='开会'   hits=1
```

两条都是**学生自己打的真实句子**，标题现在是正确的——说明修复在真实使用里生效了
（换作修复前，记进去的会是「中文的车」，然后把错误固化下来）。
按"不删学生真实数据"的原则**原样保留**。
