# 2026-10-07 两个日程表视觉刷新

## 用户 Prompt
用户截图时间轴后说：「两个日程表太丑了」。
（截图显示：浅蓝平涂色块、列太宽、留白过多、时间/标题挤在一起，整体像表格不像卡片。）

## 研判
功能层面 §6 已修通（单块跨行/分道/非整点预填/课程块不可编辑），但视觉太「平」：
- 课程块是浅蓝平涂 + 蓝边，像表格高亮；
- 列头灰小、时间标签过淡、整体留白松散；
- 列表式周表/月表卡片也用了同款 flat 样式。

决定只动 CSS，不动 JS 定位与交互逻辑；刷新后保持所有既有行为（test_29、真机探针）全绿。

## 改动（仅 `app/static/student.html` CSS，纯前端）
### 周时间轴 `.tl-*`
- `.tl-wrap`：浅灰蓝背景、圆角 14px、柔和阴影；
- `.tl-bar`：标题加粗加大，日期范围做成圆角小药丸；
- `.tl-grid`：时间列从 52px 缩到 42px，字号 12px；
- `.tl-colh`：星期加粗、日期变小变淡，today 给蓝色药丸背景；
- `.tl-daycol` 网格线改为更淡的 `#e8ecf7`，today 列略加深；
- `.tl-evt`：改卡片式——
  - 课程：蓝紫渐变 + 4px 品牌色左边 + 圆角 6px + 轻微阴影；
  - 待办：橙黄渐变 + 橙色左边；
  - hover 时轻微上浮、阴影加深；
  - 标题 12px 加粗，时间 10px 淡色放右上角，允许折行；
- `.tl-form` / `.tl-btn` / `.tl-notime .tl-chip` 同步圆角、阴影、hover 态。

### 列表式周表/月表 `.wk` / `.evt` / `.mcal`
- `.wk .day`、`.mcal .d`：白底、淡灰边框、圆角 10px、轻微阴影；today 用外框+阴影高亮；
- `.evt`：与 timeline 同色系的渐变卡片，时间单独一行、字号缩小；
- 深色主题同步：课程用 `var(--brand-soft)`，待办/完成分别用橙/绿半透明。
