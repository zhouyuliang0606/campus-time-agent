## 二、三句都认成 daily，但实测出三处不干净

| 原话 | 修之前 | 修之后 |
| --- | --- | --- |
| 从今天开始我要天天背单词 | 卡片标题成了「**从我要背单词**」 | 「背单词」 |
| 以后天天背单词 | 锚点被抠成 **2026-10-15**（跳了两天） | 从今天起 |
| 从今天开始每天背单词 | 候选只摊 **1 段**（被当成"他点名了某一天"） | 8 段，且都 ≥ 起始日 |

三个根因分别记在这儿，因为下一个加"工作日档"的人照样会踩：

1. **起手式残渣**。擦周期说法（「每天/天天」）之后剩「从我要…」，那个「从」没有任何一条擦除规则认识它。
   新增 `_START_FORM_RE`（`从/自/由` + 日子 + `开始/起/以来/之后/以后`），
   **只喂给标题擦除，不进 `parse_time_spec` 的日期那一步** ——
   那句里的「今天/明天」正是"从哪天开始"的锚点，在那一步擦掉就不知道从哪天起。
2. **整句抠日子会读出根本没说的日子**。`_pick_date("以后天天背单词")` 返回 `2026-10-15`，
   因为「以后**天天**」这四个字里连着一个「后天」。改成 `start_anchor()`：
   只在起手式那一小截里取日子，「以后/长期」这类不带介词的字样一律回空串（= 从今天起）。
3. **「说了起始日」≠「只排那一天」**。习惯天天都做，锚点只管"从哪天开始记"，
   候选该照样摊好几天让他挑。做法：摊候选前把起手式连同日子摘掉（这样不锁单日），
   摊完再按锚点滤掉比锚点早的那几天。

顺带一条误伤检查：`_START_FORM_RE` 不许把「从图书馆回来」「重新开始一段关系」吃掉 —— 有断言钉着。

## 三、代办栏：今天要做置顶，单独一个框

按他要的形状改：

```
┌ 今天要做 · 3 件还没勾 ┐   ← 单独成框，第一眼就是这个
│ 跑步 07:00   [ ]      │   ← 没勾的在前，勾完的沉底（他进来找的是"还欠几件"）
│ 睡觉 20:00   [ ]      │
│ 朗读 21:00   [ ]      │
│ 已勾那条     [x]      │
└──────────────────────┘
往后的单次任务 …
习惯（今天不归它）…       ← weekly 的日子不是今天时才出现在这儿
```

- 框用的是**没滤习惯**的那份判据（`isToday = todoOccurs(t, 今天)`）：daily 天天都算今天要做的，
  拿日历那份过滤结果来数就把最该催的漏掉了。源码里不滤习惯的调用点从此只有两处：角标 + 这个框，
  按计数钉住（多处开始漏）。
- 浅色档写死 `#f4f7ff`，**玻璃档另写一条走 token**（深色页上一块浅蓝底就是块亮斑）。
- 分组标题跟着改实话：原来叫「单次任务 / 习惯」，现在 daily 大多在今日框里，
  下面的习惯组只剩"今天不归它"的那些，标题就写「习惯（今天不归它 · 每天 / 每周）」。
