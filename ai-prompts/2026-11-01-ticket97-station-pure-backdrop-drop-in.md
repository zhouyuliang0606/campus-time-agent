> 单子。不动代码。
> 日期：2026-11-01（16:55 版修订：**L1「给驿站加自己的背景门」作废**，用户口径是驿站要「保留纯的」）
> 触发：用户原话「驿站为什么要和学生同步，学生改的东西是学生端的啊，你驿站学生又登不了」
> 补充口径：「驿站保留纯的」—— 不是「驿站有自己的背景」，是**驿站不要背景**。

## 〇 现场事实

### 0.1 谁抄了谁

`git log --oneline -- app/static/station.html`：

```
b131bb7 fix(#93 UI 口头单): /station 接上玻璃档 —— 透明 + 暗纱 + 浅字（照 #92 那一版）
88786e3 feat(#91 UI 口头单): /plan 接上背景图 —— 浅色磨砂，不动一个字色
```

`#93` 的标题自己写着「**照 #92 那一版**」。#92 修的是 `/plan`，而 `/plan` 是**学生端的日程页**——
跟 `/student` 是同一个人、同一个浏览器、同一次登录。它读 `ct_bg`（`plan.html:258`）是**对的**，
理由在 `bg.js:3-4`：「`/plan` 也要吃到学生端那张背景图，而它不该再抄一份表」。

`#93` 把这套写法搬到 `/station` 时，**把「这两个页面是同一个人」这个前提一起搬了过去**。
而驿站端不是同一个人的页面 —— 学生登不进驿站，店员也不进学生端。

### 0.2 三处书面证据

| 位置 | 原文 | 问题 |
|---|---|---|
| `station.html:433` | `key = localStorage.getItem('ct_bg') \|\| 'forest'` | 直接读学生端的键，且**默认 forest = 有背景图** |
| `station.html:427` | 注释「与学生页 / 日程页读**同一个** localStorage 键 ct_bg」 | 把错误写成规范 |
| `station.html:217` | 注释「**「设置 → 背景 → 不用图」**摘掉 html.gx-glass 总闸」 | 驿站端**没有**设置页 —— `grep 背景` 在这一页只有 217 / 292 / 427 三处，**全是注释，零 UI**。等于书面承认：驿站的背景由学生端那个设置页控制 |

第三条最难看：店员想关掉驿站的背景图，得跑去**学生端**的设置页点【不用图】。

### 0.3 判据把错误固化了

`test_56_station_shell.py:209-218`，F 批那条断言里写着：

```
⚠️ #93 起有一处**有意的例外**：外观键 ct_bg 走 localStorage —— 它不是会话数据，
   是要与学生页同步的偏好（同一台机器、同一个源）。
```

断言本体：`all("ct_bg" in ln for ln in stc.splitlines() if "localStorage" in ln)`。

这句注释把「要与学生页同步」写成了**有意为之的设计**。不改口的话，下一个人看到它会以为这是拍的板。

### 0.4 一个有利的事实：改完这页可以零 localStorage

`station.html` 的脚本里 `localStorage` 总共只出现在**两行**：`:427` 注释、`:433` 代码。
把 `:433` 那行拿掉之后，整页脚本**一处 `localStorage` 都没有**。

⇒ `test_56` F 批那条被 #93 拆成「配对判据」的断言，可以**整条收回成原来的严格版本**
（「脚本里一处 localStorage 都不许有」），比改口成 `ct_station_bg` 干净得多。

`station.html:547-551` 的值班会话用的是 `sessionStorage` + `campustime_station_session`，
与外观无关，本单不碰。

### 0.5 不受波及的部分

- `admin.html` 全文件 **0 处** `ct_bg` / 「背景」⇒ 管理端没接玻璃档（挂账第 ④ 条，另议）。
- `plan.html` 读 `ct_bg` 是**对的**，本单不动它（学生端内部两个页面，同一个人）。
- `test_44` J 批（`693-797`）**不钉键名**，只钉接线顺序、对比度、纱浓度、`classList.toggle`。
  ⇒ 本单不改它，只是 J11-bis 会从「关掉总闸时是浅色」变成「这页**就是**浅色」，仍然绿。

## 一、修法

### L0（全部，一个常量）

`station.html:430-440` 的 `applyStationBackdrop()`：

```js
// 改前（:431-435）
const root = document.documentElement, img = document.getElementById('gxBg');
let key = 'forest';
try { key = localStorage.getItem('ct_bg') || 'forest'; } catch (e) { /* 隐私模式读不到就用默认 */ }
const on = (key !== 'none') && window.CT_BG_SRC && window.CT_BG_SRC[key];

// 改后
const root = document.documentElement, img = document.getElementById('gxBg');
// 驿站端**不读任何外观键**：这台机器是店员的，学生不进这页（#97）。
// 学生端设了什么都与这里无关；哪天要给驿站自己的背景，改这一行 + 加一个只写不读别处的入口。
const key = 'none';
const on = false;
```

`on = false` 恒成立 ⇒ `html.gx-glass` 永远不加 ⇒ 以下整段全部失效，页面回到**基线浅色原样**：

- 页面自己那半段 `html.gx-glass …` 规则（`station.html:217-290`）
- `glass.css` 的 `.tk-rain` token 与玻璃层
- `#gxBg` 那张 `<img>`（`:297`）永远没有 `src`，`display` 由 CSS 的默认值决定 —— **要顺手确认它是 `none` 或不占位**，否则纯色页上会留一块空白

最后一点是实操最容易漏的：现在 `on=true` 时走 `img.style.display=''`，
改成恒 `false` 之后走 `img.removeAttribute('src')`（`:438`）。
一张没有 src 的 `<img>` 在多数浏览器里是 0×0，但**要在真机上确认一次**，别让纯色页顶上多一道白条。

### L1（作废）

16:55 版里我建议「给驿站加一颗自己的 🎨 背景门（`ct_station_bg`）」。**用户口径是「驿站保留纯的」，整条作废。**

理由是原话：「驿站保留纯的」——要的是没有背景，不是「驿站有它自己的一份背景」。
加门等于把「驿站需要背景图」当成需求，那是我自己推的，不是他要的。

### L2（挂账，今天不动）

改完之后，`station.html:217-290` 那半段玻璃规则 + `glass.css` 的 token 就成了**永不生效的代码**，
`test_44` J 批 37 条判据守着的也是一组不会生效的 CSS。两种处置，**等拍**：

| 选项 | 代价 |

## 二、判据改口

### 2.1 `test_56_station_shell.py:209-218` —— 收回成严格版

**断言**：

```python
# 改前
and all("ct_bg" in ln for ln in stc.splitlines() if "localStorage" in ln)

# 改后
and "localStorage" not in stc
```

**注释整句重写**（不能只改断言、注释留着旧口径）：

```
①会话固定了但【清空】还只擦屏幕（F5 全捞回来 = 清了跟没清一样）；
②用了 localStorage（两个标签串成一段对话，正是柜台最常见的用法）。
所以顺序、载体、换新 id 三样分别钉，并配一条「旧写法不许留」。

⚠️ #93 曾在这里开过一个例外：外观键 ct_bg 走 localStorage，理由是「要与学生页同步」。
   #97 把那个例外收回了 —— 驿站是**店员机器**，学生不进这页、店员也不进学生端，
   「同一个人的两个页面」这个前提不成立（#93 是照 /plan 抄的，把前提一起抄了过来）。
   所以判据回到严格版：**脚本里一处 localStorage 都不许有**，外观也一样。
```

### 2.2 新增两条

```
F-x 正控：脚本里 sessionStorage 必须还在（证明不是把整个存储层删干净了事）
         —— `stc.count("sessionStorage") >= 2`（getItem + setItem 各一处）
F-y 驿站端不许出现任何「外观键」字样：`re.search(r"ct_bg|ct_station_bg|ct_bg_scrim", stc) is None`
```

F-y 配正控：`bg.js` 的引用必须还在（`'src="/static/bg.js"' in src`）——
证明是「不读键」而不是「把 bg.js 也删了」（删了 `test_44` J1 会红，那属于 L2 的选项乙，不是本单）。

## 三、变异（打在判据上游）

| 编号 | 变异 | 必须红的地方 |
|---|---|---|
| M1 | `const key='none'` 改回 `localStorage.getItem('ct_bg')` | 真机第 ① 步（学生端设 deep ⇒ 驿站跟着变）＋ 2.1 |
| M2 | 保留 `key='none'`，但加一行 `getItem('ct_station_bg')` 兜底 | 2.1（`"localStorage" not in stc`） |
| M3 | `const on = false` 改成 `const on = (key !== 'none')` | 这条**不该红**，因为 `key` 恒 `'none'` —— 它是等价写法，留着无害 |
| M4 | 只删 `getItem` 那行，忘了改 `on`（`on` 仍算 `CT_BG_SRC['none']` = undefined ⇒ false） | 同样不红。**但要在真机确认 `#gxBg` 没有 src 时不占位**（见 L0 末尾） |

M3 / M4 特意列出来是因为它们**不红**：这单的正确形态有几种等价写法，
判据只该钉「读不到学生端的键」和「页面是纯色」这两件事，不该钉具体常量写法。
如果执行方写成 M3 那种，只要 2.1 和真机过，就算对。

## 四、真机两步

同一台机器、同一个浏览器（唯一能暴露串键的条件）：

| 步 | 操作 | 期望 |
|---|---|---|
| ① | 学生端 `/student` → 设置 → 背景 → 选「深夜」；再开 `/station` | 驿站端**纯色浅底**，没有任何背景图 |
| ② | 学生端 → 设置 → 背景 → 选「不用图」；再开 `/station` | 驿站端**看起来一模一样**（第 ① 步和第 ② 步的截图应当无差别） |

第 ② 步是关键：它证明驿站端**根本不参与**这个开关，而不是「碰巧被设成了同一个值」。

顺手看一眼：纯色页顶部、`#gxBg` 那一层的位置**没有白条或空白块**（L0 末尾那条）。
