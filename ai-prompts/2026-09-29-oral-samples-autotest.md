# 2026-09-29 口语样例大批量自测（去重/全删/单条/纠正/模糊/省略/错别字 + RAG）

## 一、用户 Prompt（原话）

> 生成一批，每组重复条目删掉一条，全部删掉，删掉指定单条，纠正对话，模糊口语，
> 省略句，自然对话（带错别字，由ai自行识别）rag知识库问答的测试对话样例，去进行自主测试

一句话里点了 **7 类口语 + 1 类 RAG**，而且明确说了「**由 AI 自行识别**」（错别字不许靠我人工标注）、
「**自主测试**」（要我自己跑、自己判、自己修）。

## 二、AI 研判

前面几批（test_12/13/14）钉的是**每一种意图的标准说法**。可学生的嘴不是标准说法。
这一批要回答的是另一个问题：**系统能不能接住人话**。所以每条样例都写成"一个完整的小对话"
（前情 → 这句 → 看结果），而不是孤零零一句话——"都删了"三个字离开上一句清单就没有意义。

**红线贯穿全批：只要学生没点头，一条都不许删。** 每批最后都核对库里条数，
把"猜测"和"执行"这两件事彻底分开（猜测可以大胆，执行只能在他点头之后）。

先**基线探测**（`_probe_oral.py`，20 句真人口语）再动手，探测出 7 个真缺口：

| # | 学生说的 | 改之前 | 缺口性质 |
|---|---|---|---|
| 1 | 把**游永**删了 | "没找到这条待办" | 打错字认不出 |
| 2 | **删悼**交电费 / 把晨读**删叼** | 跑去给他排空档（当成加待办） | 打错字的删除动词认不出 |
| 3 | 上次那个事**不要了** | 掉进加待办/查空档分支 | "不要了"这类软删除说法没进删除开关 |
| 4 | **不是这个，是交电费** | 傻傻重列一遍清单 | 纠正句里带新名字时不会切换 |
| 5 | 帮我把交电费去掉**呗** / 游泳删掉**把** | 卡上写出「把交电费呗」 | 语气词/倒装的"把"粘进名字 |
| 6 | 把**那个啥**删了 / 上次**那个事**不要了 | 干巴巴一句"没找到" | 指代词被当成"点了名"，池子被筛空 |
| 7 | **校车在哪坐**（日程栏） | 被"查日程"接走/被模型现编 | 见第五节（真机才暴露） |

## 三、改动（按文件）

**`app/modules/planner.py`**
- `_DEL_ANY_RE` 收成 `删[^，。！!？?、\s]{0,1}`（原 `{0,2}`）—— 再宽就会把
  「删**除撞**时间的代办」的"除撞"一起吃掉，名字只剩"时间"（这条是我自己引入又自己抓回来的回归）。
- 新增 `_REMOVE_TODO_SOFT`（不要了 / 不去了 / 不搞了 / 算了删 / 取消掉 / 去掉吧 / 删了吧），
  同时并进 `wants_remove_todo`、`wants_remove_todo_loose` 与 `wants_add_todo` 的**让位判定**
  （`wants_add_todo` 先让位，删除分支才接得住）。
- `_pick_todo_name`：擦"一下/一下下"**要排在擦删除词之前**（否则「删+一」被整块吃掉，
  只剩一个「下」赖在名字里）；补擦否定词（不是这个/不对/换一条/我要的是…）、句首「是」、
  语气词与句尾「把」。
- 新增 `_VAGUE_NAMES` 闸门：那个/这个/啥/什么/事/东西 这类**指代词不算点名**——
  算成点名会把池子筛空、只能回"没找到"；不算点名则池子是全库，走"列清单问是哪一条"，有用得多。
- 新增 `_lev()`（编辑距离）+ `_fuzzy_name_match()` / `_fuzzy_name_hits()`，
  `resolve_todo_remove` 增加第三档兜底 `fuzzy`（等价组优先 → 单条 → 否则列清单）。
- `resolve_todo_remove_reply`：说"不对/不是这个"时**先按新名字解析一遍**，解析不到才重列清单。

**`app/main.py`**
- 新增 `_kb_has_answer()`；「看不见 X」抱怨句在知识库答得出来时**让路**（不再把它吃成"确实还没有 X"）。
- 盲删（没点名）的"已经不在了"从**解析之后**挪到**解析之前**：他没点名时解析只会拿回"全部待办"，
  等走到后面再说"已经不在"已经晚了（详见第五节自踩回归）。
- 新增 **3i 知识库直答**分支（见第五节）。

**`app/modules/faq.py`**
- 新增 `_kb_fuzzy_hit()`（滑窗 + 编辑距离），`search_kb` 精确匹配落空后补一遍错别字匹配。

**`app/static/confirm.html`** — 卡上显示「挑它的依据：……」（`picked_by` + `note`）。

## 五、真机验证（这一轮最值钱的一课：沙箱会"假绿"）

沙箱里 `settings.json` 被清掉 → 没密钥 → 语义层静默 `None`、模型兜底变成 Mock。
**"接口没被抢走"这类断言在沙箱里天然就绿**（答的是"没配密钥"），根本没验证到东西。

真机（后端 8000 重启后）拿**真实 4 条待办**喂了一遍（只出卡、不点确认 → 一条没写库）：

| 学生说的 | 真机结果 |
|---|---|
| 把写作业删了 | ✅ 出《写作业》确认卡 |
| 把**写做业**删了 | ✅ 也出《写作业》卡——但**卡上一个字没提"我当你是打错字了"**（漏子①） |
| 体检预约删掉**把** | ✅ 名字干净：《体检预约（校医院）》 |
| 帮我把交计算机网络作业去掉**呗** | ✅ |
| **校车在哪里坐**（日程栏） | ❌ 模型现编："我这边查不到，你去看学校公众号"，**知识库里明明有校车时刻表**（漏子②） |
| 我的校车待办显示不出来 | ✅ 仍是报障（给待办列表） |

两处修复：
- **①** 错别字只捞到**一条**时早先走的是"唯一命中"分支，不带 `note`。
  学生打错字、系统替他改了名字还不说，他会以为本来就有一条叫这个的 → 看都不看就点确认。
  改为：只要靠"打错字"捞上来，就必须写明依据（`picked_by=fuzzy_name`）。
- **②** 新增 **3i 知识库直答**分支，位置放在**所有确定性分支之后、交给模型之前**
  （该接的都接过了才轮到它，绝不从待办操作手里抢话），四道闸门：
  手上没待确认的卡 / 不带"待办·日程·课表"等词 / 没有任何改数据的意图 / 像问句且知识库真答得出。

## 六、自踩自修（诚实记录）

改完先跑全量，**被我自己撞红 2 条老用例**：

1. `test_11` 「10月三号两个撞时间的代办删一下」抠出的名字变成 `"下"`
   —— `_DEL_ANY_RE` 收窄到 `{0,1}` 后，「删+一」被吃掉只留「下」。
   修：把"一下/一下下"的擦除**提前**到擦删除词之前（同一个词表，顺序反了就出事）。
2. `test_08` 「不去了删了吧」（那条已被手动删过）不再回"已经不在日程里了"，
   改回"对上了好几条待办，我不敢替你挑"
   —— 因为新加的软删除词擦除让 `name == ""` → 不算点名 → 池子变成"全部待办"。
   修：把"已经不在了"这条支路从**解析之后**挪到**解析之前**（有回执可查时先如实说，不去解析）。

修完这两条再跑：**全量 1301 通过 / 0 失败（15 批）**（此前 1245/14 批）。

## 七、教训（写进技能与项目记忆）

1. **沙箱"假绿"**：凡是"不该被某条路接走"的断言，沙箱里因为没密钥天然成立。
   这类断言必须**把判据本身也钉一条**（`_kb_has_answer(...) is True/False`），并**上真机复验**。
2. **擦除顺序是语义**：同一个词表，谁先擦决定结果（"一下" vs "删+一"）。
3. **改全局开关必跑全量**：`wants_add_todo` 是全项目共用开关，动它就是在动所有分支。
4. **指代词不是点名**：把"那个啥"当成点名会把候选池筛空，答案从"列清单"退化成"没找到"。
