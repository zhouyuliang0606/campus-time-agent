## 四、两处偏离施工单，都有实测撑着（这是本单最值钱的部分）

1. **`#log` 不能照抄 `max-height:none`**。施工单 §3.2 让撤掉旧的 440px 限高、改 `max-height:none`，
   但它自己 §7 的第 3 条验收要的是"**页面不滚** + **`#log.scrollHeight > #log.clientHeight`（内容在内部滚）**"。
   这两句在它给的改法下不可能同时成立：`#log` 不限高就一直往外撑，滚的会是外层，
   于是"上下翻"只从页面挪到 stage —— **他要的正是不要翻**。
   改成 `#view-chat.active{display:flex;flex-direction:column;height:100%}` + `#log{flex:1;min-height:0;overflow-y:auto}`，
   并把旧的 `min-height:300px; max-height:440px` **在原规则里就地删掉**（不是在末尾盖一层）。
   实测：529×535 视口下 `documentElement.scrollHeight == innerHeight == 535`（不滚），
   `#log` 是 2345 vs 255（内部滚），输入框底 521 ≤ 535（钉在视口内）。
2. **窄屏那句 CSS 会把角标一起藏掉**。施工单写 `.sb-item span:not(.ico) { display:none }` 收文字，
   而 `.sb-num`（角标）也是个 span，特异度 (0,2,1) 压过 `.sb-num.show` 的 (0,2,0) ——
   529px 实测 `getComputedStyle(角标).display = "none"`，那颗"未结几条"的红点**根本不显示**。
   改成 `:not(.ico):not(.sb-num)`，并在 `.sb-num.show` 里自己声明 `display:inline-block`。
   这条我落成断言（V2 回到原样就咬红），因为**这次改造的补偿机制就是那颗点**。

另有一处小改：左栏按钮的文字包进 `<span class="lbl">`，否则窄屏那句收不到裸文本节点。

## 六、S2 没做，而且我建议先别做

施工单自己标了"要拍板"，理由我也认：固定 session 会让驿站客服**开始记得上一句**，
而驿站是一台**公用机器** —— 会不会把上一位同学的问题带到下一位身上，只能真机试，不能靠推断。
另外它和【清空】是**同生共死**的：一旦服务端真存了历史，清空就必须先清服务端、成功了再清屏幕。
现在这版【清空】的实现（纯前端 + 注释写明为什么不调 reset）就是按"没有服务端记忆"这个前提写的。
已把这一条挂进 `EXPLAIN.md` 六，等他点头。
