## 一、45-C 落地（`0ef7230`）

接缝只加在 `app/agent/pending.py` 一个私有函数上，**对外签名一个字没改** —— `main.py` 那 30 多个调用点全没动：

```python
def _key(session_id: str) -> str:
    if not session_id:
        return ""
    from app.store import current_owner      # 函数内导入：pending 有可能比 store 先被加载
    return f"{current_owner()}|{session_id}"
```

六个调用点全换（`save` / `peek` / `take` 的两处 / `mark_applied` / `clear` / `_pending_entry` 自己那次 `pop`+落盘）。
`_pending_entry` 的形参改名为 `key`，因为拼身份只在五个出口各调一次 —— 最容易被漏的就是它自己那次 `pop`。

`login.html` 换人时 `localStorage.removeItem("campustime_session")`，**只清这一个键**；
护栏 C5-bis 反过来钉住「不许 `localStorage.clear()`」（那是把 `ct_bg` / `ct_profile_name` / `ct_model_cfg` 这些偏好一起弄丢）。

两个后果照单子写实进了提交信息：老裸键读不到（要的，TTL 自然清，**不加清理逻辑**）；cookie 掉了看不到自己刚出的卡（可接受）。
