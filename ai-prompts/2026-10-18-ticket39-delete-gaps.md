## 一、全局扫描的复算（"只增不删"到底有几处）

单上的结论是四处真缺口，我这侧按 store 写入口 × 前端删除入口逐个对账，**结论一致**：

| 数据 | 有删口吗 | 判定 |
|---|---|---|
| 知识库条目 / 待办 | `delete_kb_entry` / `delete_todo` + 前端都有按钮 | 不缺，**别顺手改** |
| 工单 | 软删（`archived`）+ 管理端「🗄 已归档 N 条」 | 不缺，但**驿站那一半缺**（→ 39-C） |
| 驿站服务定义 | 只有 `add_service` | **缺**（用户点名） |
| 驿站登记记录 | 只有 `add_custom_record` | **缺**（用户点名） |
| 通知 | 只有 `add_notice` | **缺**（发错别字下不来） |

## 三、两处照抄施工单会静默失效（同一条纪律第三次撞）

| 单上写的 | 实测 | 后果与对策 |
|---|---|---|
| §39-C③ 登记那块挑 `x.status === "已处理"` | **词表里没有「已处理」**：登记记录与工单共用 `_WO_STATUSES` = 待处理/处理中/**已解决**（`station.html:653` 那句旧注释还专门说过"不许工单叫已解决、登记叫已处理"） | 照抄得到一个**永远不挂、也不报错**的历史面板 —— 比崩溃更难发现。判据改成 `已解决`，「已处理」只当标题的人话。配 E14 + 变异 M7 |
| §39-C② 那行插在 `box.innerHTML = ""` 之后、`forEach` 之前 | 上面有一道 `if (!list.length) { 画空态; return; }` 的**早返回** | "全部办完"那一刻正是最需要这行的那一刻，照抄就永远挂不出来。两条分支都挂（E7 钉位置 + 变异 M6），并在真机复现：副本起手 9 条全归档、未结为空，那行照样挂出来（「已处理 10 条」） |
| §39-D③ `onclick="recallNotice('${esc(n.id)}')"` | **`esc.js` 顶部自己写着这是禁区**：内联 JS 字符串字面量里 `&#39;` 会被 HTML 先解码回 `'` 再交给 JS 解析，转义挡不住语法破坏 | 改成 `data-notice` + `addEventListener`（E8 钉这条，并要求 `recallNotice` 这种全局函数根本不出现） |
| §39-D③ `if (!resp.ok) return;` | `adminFetch` 非 2xx 一律**抛**（#28 的收口就在这一处） | 那句永远走不到，而不 catch 就是"点了没反应 + 未处理拒绝"。补就地 try/catch + 状态行（E9） |
| §39-A/B 用原生 `confirm()` | 这一页 182 行注释就写着"连点几次会被浏览器拦" | 原生框被拦之后就是"点删除没反应"。admin 有 `askConfirm` ⇒ 改用它；station 以前没有 ⇒ 这轮补一份 `stConfirm`（**一页一份**，没全站统一，写在指南里免得下一位误会） |

## 四、一次主动收窄旧钉子（这条最值得留档）

`test_58` D 批原来钉的是：**驿站那一段代码里不许出现 `archive` 这个词**（守"免口令面不能收台账"）。
39-C 要的恰好是驿站的一段只读历史视图 —— 词一样、性质不同：数据没跨过端，只是不再凭空消失。

改法不是"把那条删掉"，而是换成钉**写口**：
```python
_deco = [ln for ln in seg.splitlines() if ln.startswith("@app.")]
写口 = [ln for ln in _deco if "/archive" in ln and "/archived" not in ln]   # GET 那条允许
```
外加 `set_workorder_archived` / `set_message_archived` / 管理端依赖都不许出现在那一段里，
并**补一笔变异 M10**（把那条 GET 改成 POST）确认改口之后仍然咬得住。

⇒ 改一条护栏的标准动作就此定下来：**说清它真正防什么 + 一笔变异验牙，少一样都别改。**

顺带两处"计数当判据"自己撞自己：`test_53`「那一窗 innerHTML 只许 1 次」（39-C 加了第二处**也是清空**）、
`test_58`「全页只有 5 处 `!resp.ok`」（39 加了四处**同形守门**）。
都从"数数"改成钉**性质**（每一次 innerHTML 都必须是清空赋值；数量随实测走但"不许抽公共 fetch 层"一字不松）。
