# 2026-11-04 · #118（口头单）「周末打篮球，四个小时」无 Key 也认周末和时长：候选落周末、准入按 ≥、装不下说人话

## 一、用户 Prompt 摘录

**口头单，无原件**，来源是 2026-11-04 演示前收口会话里的学生对话原话 + 用户三条拍板。规则先行（用户原话要点）：「编号你别按号理解，我说的时候会给你现象，你听完先别急着动手，先问我三件事——范围、判据、不做的事。问完我再拍板。」

**现象**（用户实测，2026-11-04）：同一句「周末打篮球，四个小时」，配 Key 走语义层是正常的；**没配 Key 走 chat 路由，候选还是从今天往后按天铺**，落在周三、周四、周五。他把哪天方便说得最死的一次，系统当成他没说。存量问题、不在任何已有单子里；修法与 #114 的 1.5 是一族（范围词与具体日子冲突时让位），但要动的是 **chat 路由的候选选择（mock_planner §5），不是 candidate_slots 那一支**。

**用户三条拍板**：

1. **范围**：只动 `mock_planner`，但 §5 必须连 `_guess_title` 一起算——实测 `_guess_title('周末打篮球，四个小时')` 原样返回，而前端确认回传是 `确认 <日期> <起-止> <title>`（student.html:1999）、§3 写库用同一个函数 ⇒ 不修它，库里会存进「周末打篮球，四个小时」这种名字。它只有两个调用点（:1779/:1809），都在 mock_planner 里，口径没扩到别处。时长**不另写换算**，直接调 `wanted_minutes()`（实测该句返回 240），读不出回 60。周末窗：周三说 → +3/+4；今天就是周六 → 今天+明天；今天是周日 → 按下周六日（+6/+7），同一把尺、没有特例分支。
2. **判据**：每段 `minutes >= 240`——是**准入线不是段长**（`find_free_slots` 返回整段空档，`minutes = e - s`，60 只是门槛），**不许写 `== 240`**。对照句连名字一起钉：「周三下午打篮球」「晚上打篮球」的事名也得是「打篮球」。「真机周末有 4 小时空档」不成立（实测 `find_free_slots('2026-11-07', 240)` = `[]`，周六被**待办**占到 22:00 只剩 50 分钟）⇒ 真机这句走的是**诚实话**那条，不出卡。变异两笔必须跑在**夹具**上——真机数据上摘判据会因周末本来就满而变成"诚实话"，是哑弹；摘周末判据那笔要能看到候选跑到周三/周四/周五才算有牙。
3. **不做**：§2 `need_upload`（`if not get_timetable()`）本单不动（另记一条：无 Key + 身份没课表时任何句子都到不了 §5，评委克隆环境看到的是"先上传课表"，不进本单）；不动 candidate_slots；不动 `kb.json`；不起 8000（「你改完我这边自己起服务验，你不要起服务」）。

## 二、AI 研判与决策（含为什么不那么修）

- **§5 候选窗**：写死的 `base+0/1/2` 换成两支——有 `_WEEKEND_WORDS`（周末/双休）就走 `sat_off = (5 - base.weekday()) % 7` 的周六+周日两天窗（周三+3/+4、周六+0/+1、周日按下周六日 +6/+7：这个周末只剩今天，与"往后找"同解）；没有就照旧铺三天。**没做**"周末+具体日子同时出现时让位"的 #114-1.5 同款逻辑——§5 的入口语义层早把日子解析完了，到 Mock 这层句子要么带周末词要么带具体日子，现状没有两者并存的真链路，造让位是给假需求写代码。
- **时长准入**：`min_min = wanted_minutes(msg) or 60`，传给 `find_free_slots(d, min_min)` 当准入门槛。空档是整段返回的，所以 900 分钟的空档也是合法候选——判据钉 `>=`。
- **诚实话**：`opts` 为空时先探一遍 `find_free_slots(d, 1)`：报了时长就明说「这个周末/最近几天的空档最长只有一段约 N 分钟，放不下你说的 M 分钟」；没报时长走原来的通用 empty 档（W7 正控钉住——没报时长的路不许被改口风）。**只在报了时长时接管**，避免把"这几天空档不太够"的既有话术一锅端。
- **`_guess_title`**：`_DATE_RE` 之后加一段擦除——`_WEEKEND_WORDS + _WORKDAY_WORDS` 整词替换、`_WEEKDAY_RE`、`_DURATION_RE`、时段词表（与 `_prefer_window` 的词表同源）、标点残渣收尾。「分」那颗只在「N分钟」整词里剥（`_DURATION_RE` 要求带单位），「三分球」这类不受影响（T6 正控 + T7 双词叠加钉住）。
- **为什么不那么修**：不在 §5 里复刻 #114 的 `_strip_freq_keep_range`——那是给"频次词和范围词粘在一起"的语义层入口用的，Mock 这层没有频次展开；不把诚实话做成选项卡——装不下就是装不下，摊出 <240 的候选正是 M2 变异要抓的谎；不动 §3 的确认写库路径——`_guess_title` 修好后 §3 自然受益，同一函数不用第二把刀。
