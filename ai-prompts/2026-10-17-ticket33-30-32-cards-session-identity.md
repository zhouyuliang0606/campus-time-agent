## 一、#33「点确认 → 刷新 → 卡又回来 → 再点又加一条」

用户 01:40 真机原话：**「我先前加入一个代办，点击确认后，退出去刷新回来，又弹了一次卡，再点击确认重新加了一个相同代办」**。

### 前提实测（施工单的定性对，落点名单不对）

| 前提 | 实测 |
| --- | --- |
| 是不是今晚改出来的 | **不是**。`todo_add` / `mark_applied` 都是 09-25 `9e12370` 引入，同一笔给批量补了销卡、漏了单条 —— 施工单这条定性我复现不了也不需要复现，看 git 就够 |

| `PUT /api/todos/{tid}` | 改前**连 `session_id` 都不读**，施工单的代码块假定了已有一个 `sid` 变量 —— 按当前代码补 |

| `/api/workorders` 要不要一起改 | 不用。它已经用 `clear_pending(sid)`（拿走式）销卡，是**另一套但有效**的机制 |

## 二、#30 驿站端固定一段会话（#25 S2）

拍板依据是用户 01:26 那句：**「驿站是店员，学生通过自己 ai 可以给驿站发消息」** ⇒ 学生不碰这台机器，
"上一位带到下一位"的顾虑不存在了。

**落地**（`9244cc1` + `4f2650f`）：`stationSid()` 用 **sessionStorage**（刻意不同于学生端的 localStorage：
关窗即"这次值班结束"、柜台常开两三个标签会串味、同标签 F5 不丢）；`/api/chat` 带上 `session_id`；
【清空】从"只擦屏幕"升级成**先清服务端 → 成功才擦屏幕 → 再换新 id**，失败直接 `return` 并说「聊天记录原样保留」。

**一处改口**：`test_56` D 批原来钉「不许调 `/api/chat/reset`」，理由是"每轮都是新 session，清服务端是个谎"。
会话固定后这个前提**反了** —— 服务端真存着这段对话，只擦屏幕才是另一种谎。旧断言换成"必须调它"，
新的三条（顺序 / 失败分支 return / 换新 id）钉在 F 批；回执文案变了，所以那条比字符串的断言收窄成
「台账一条没动」，不再钉整句。**同轮 `test_58` 的一条锚点也跟上**（`/api/chat` 请求体多了 `session_id`），
并把 `_fn_body`/`_action_span` 从"抛异常"改成"返回空串"：抛出去会把整批打断成崩溃，
而崩溃不产生 ❌ —— 这是我自己的锚点过时踩的第十次 4f。

变异 M1~M6（含 M2b 顺序反）逐笔有牙。**真机**：两轮提问 + 一句指代上一句（「那第二个呢」→ 正确答出 B-5678 运动鞋）；
F5 之后 sid 没变、服务端历史 4 条还在、第三句仍接得住；把 reset 打成不存在的路径 → 「清空没成功，聊天记录原样保留」
且**屏幕一个字没擦**、sid 没换；正常清空 → 换新 sid、旧会话服务端归零、F5 不复活；
跑 5 轮只多 **1 个** `st*` 会话（真实库现状：659 个会话、511 个只含 ≤2 条、316 KB）。

**没做（要他点头）**：§6 那 580 个随机 uuid 会话的清理。规程我认可（备份→只删"随机 uuid 且 ≤2 条"→复核），
但那是**删用户的运行时数据**，等他一句话。

## 三、#32 学生身份：同一台机器换账号，个人库不共用

用户 01:36 原话：**「学生账号不要两个机器，同一个机器退出登录后，切另一个账号，课表代办属于个人数据库不能共用」**。

**落法**（`a9b1d7e` / `c24c670` / `7ba642f` / `ce35a8a` / `7bfef2f`）：
身份=学号（演示级、不设密码），载体=**cookie** `ct_student`（浏览器每次自动带 ⇒ 学生端几十个 fetch 一个字不改；
加请求头要动几十处、**漏一处就是一次静默串号**），接缝=**`_spath` 一处**（课表/待办/会话自动分开），
兜底=没学号走老位置 `student/`，中间件 `bind_student` 是**唯一**一处设身份。
`_CURRENT_STUDENT` 用 ContextVar 而不是模块级全局（并发下会互相盖掉，出现"A 的请求读到 B 的学号"）。

**红线**：学号会被**拼进文件路径** ⇒ 白名单 `^[A-Za-z0-9_-]{1,20}$` 且**两处都过**
（登录处 + 中间件处 —— 只在校验登录等于门锁只装了一半，cookie 是可以手改的）；
不合法一律 400 一句人话，**不许默默回退到默认学生**。播种 `todos.json`/`timetable.json` 两道闸
（目录已存在就返回 + 单文件已存在就不拷），**不拷对话历史**。

**我自己加的两处**：
① `/api/whoami` —— 顶栏要显示"现在是谁"，读本地那份副本不可靠（它只是显示用）；
② 未登录**不硬跳转**：那一格标成「👤 未登录 · 演示公共库」并给一个去登录页的点击入口。
理由：直接打开 `/student` 这条老路还得留着（README 复现、录屏、评委随手一敲），
把它变成来回弹白屏比"少一个身份"更坏；而后端兜底本来就走老位置，§5.5 那条验收要的正是这个。

**真机抓到一个我自己写的真 bug**：登录页第一版 `go()` 定义得好好的，
**忘了给【进入】`addEventListener`** —— 点下去什么请求都不发（没报错、没提示、console 干净、
`node --check` 也过）。语法检查、接口测试、读代码**全都发现不了**，只有真按一次才知道。
已接上线，并补一条护栏 C5-bis（三颗按钮都有监听 + 提交只有一处 fetch）。

**护栏 33 项**（`tests/test_59_student_identity.py`）里两个值得记的点：
- A2 周表那条第一版钉"S002 的周表里没有《高等数学》"—— 错：S002 的库是登录时从底稿**种**出来的，
  18 门课本就含它。改成"S001 存课之后 S002 那份**一个字节没变**"，这才量的是"分没分开"。
- C2-bis "main 里不许自己拼 student 路径"如果写成"搜 student 这个词"会被 JSON 键名 `{"student": …}` 误伤
  （本仓"注释绊红"的同一族，只是这次绊它的是**键名**）。改成按"`os.path.join` 里出现 `"student"` 字面量段"判。

**变异 M1~M7 逐笔有牙**（`mutate32.py`），两处记下来：
- **M5 第一版是绿的**：只摘了函数开头"目录已存在就返回"那道闸，而下面逐个文件时还有第二道
  `not os.path.exists(dst)` 挡着 ⇒ 行为没变回去，绿是对的、**变异是错的**。补齐两道才红（教训 4l 又一次）。
- M3/M6 会把非法学号真当身份用，可能在系统 Temp 下造出空目录；脚本先记录存在性、跑完只删
  "原本没有、这次被造出来"的那几个，不无脑 rmtree。

**真机 §5 八条**：登录 S001（chip=👤 S001、cookie 带上）→ 加待办 + 一句私话；
退出 → 登 S002：待办只剩底稿那条、**看不见 S001 的**、新 session 历史 0 条（本地对话 id 也换了）；
S002 加自己的一条 → 退出 → 登回 S001：只见自己的，S002 那条不在；
清 cookie 直开 `/student`：不报错、走兜底、标"未登录 · 演示公共库"；
6 种非法学号全 400 一句人话且没被发 cookie；副本 `student/` 下只多出 `S001/`、`S002/` 两个目录，
老位置底稿与真实 `app/data` 451 文件**零变化**。
