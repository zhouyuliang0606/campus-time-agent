## 二、为什么 #105 必须等 #106，而不是反过来

#106 改的是**函数入口与取数**（签名加 `exclude_id`、把两次 `list_services()` 合成一次并排除自己）；
#105 改的是**取完数之后的那段循环**。

如果 #105 先做，#106 合并时会出现两处打架：

* #105 的循环用的是原来那句 `existing = list_services()`（含自己）；
* #106 要把 `existing` 换成 `rows`（已排除自己）。

两个人都动 `existing` 这个名字，先做谁后做谁都要重排一次。**让 #106 先落，#105 就只是在最终形态上插一段循环，不用二次返工。**

反过来（#105 先做、#106 后做）也不是不行，但那时 #106 必须把 #105 新写的那段循环里的 `existing` 一起改 —— 容易漏，漏了的症状是「编辑服务时把自己剔掉了一半、另一半还在撞」。**这个症状很难查，别给自己找。**

## 三、#106 落地之后，#105 应该抄这份（合并形态）

> 下面这段是**两单合并后的最终样子**。执行方做完 #106 之后，直接把 #105 的那段循环插进去，
> 不需要再自己拼。变量名以 #106 落地后的实际代码为准。

```python
def validate_service_def(obj: dict, exclude_id: str = "") -> tuple:
    ...
    rows = list_services()
    # #106：编辑自己时把自己从"已被占用"里拿掉 —— 否则下面两道闸都在跟它自己较劲。
    rows = [s for s in rows if not exclude_id or str(s.get("id")) != exclude_id]
    taken = {str(s.get("name") or "") for s in rows}
    if clean["name"] in taken:
        return None, f"已经有一个叫「{clean['name']}」的服务了，换个名字或先删掉它"

    short = [t for t in clean["triggers"] if len(t) < TRIGGER_MIN_LEN]
    if short:
        return None, (f"触发词「{short[0]}」太短了（不到 {TRIGGER_MIN_LEN} 个字）：…")

    # ── 以下为 #105 插入的那一段（上面两闸是 #106 落地后的形态，别动）────────
    existing = rows                    # ← 关键：#106 已经排除过自己了，这里不许再调 list_services()
    kept, dropped = [], []
    for t in clean["triggers"]:
        hit = None
        for other in existing:
            for oth in [str(x) for x in (other.get("triggers") or [])]:
                if t and oth and (t in oth or oth in t):
                    hit = (str(other.get("name") or ""), oth)
                    break
            if hit:
                break
        if hit:
            dropped.append((t, hit[0], hit[1]))
        else:
            kept.append(t)

    #    裸判会把「只写 1 条、什么都没撞」的合法定义全拒掉（#105 T7 钉着这一条）。
    if dropped and len(kept) < TRIGGER_MIN_KEEP:

        return None, (f"触发词「{t}」和已有服务「{oname}」的「{oth}」撞了，"
                      f"剔掉它之后只剩 {len(kept)} 条，学生换种说法就找不到这项服务了。"
                      f"换个**不含**「{oth}」的说法，比如把「{t}」写成「{_suggest_alt(oth)}」。")
    clean["triggers"] = kept
    # ── #105 插入结束 ─────────────────────────────────────────────────
```
