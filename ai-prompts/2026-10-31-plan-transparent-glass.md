## 二 为什么"透明"必须连字色一起改（#89 那条病的正反两面）

`/plan` 是全站唯一一张通体**深字压浅底**的页面（`body{color:#1f2733}`，19 条不透明浅底）。
表面一透明，字底下就变成「照片 + 纱」—— 这正是 #89 上午刚修掉的那个 bug 的形状：
**CSS 不报错、页面照开、只是读不出字**。实测（同一套 WCAG 相对亮度，反控钉在 I5）：

- 旧那句深字 `#1f2733` 压在**最亮那档**照片 + 这页自己的纱上 = **1.15:1**（正文门槛 4.5）。

所以这三件是一个动作，不是三个选项：**表面透明 + 字色翻浅 + 页面自己垫一层暗纱**。
暗纱复用公共层的 `.gx-veil`（不在这页重抄遮罩实现），只写这页自己选的浓度
`--gx-scrim:.42 / --gx-vm:.46` —— 比学生页按图反解的那档更沉，因为这页没有卡片底色替字垫底。
口径与 #89 一致：整段只挂 `html.gx-glass`，「设置 → 背景 → 不用图」一摘总闸就整段失效、回到浅色原样，**不养第二套样式**。

## 三 改了哪些规则（`41f8674`，numstat **52/29**，只 `app/static/plan.html` 一个文件）

结构三处：`<body>` 开头补 `<img class="gx-backdrop" id="gxBg" … aria-hidden="true">` +
`<div class="gx-veil" aria-hidden="true">`，内容层 `<header>` 与 `<div class="wrap">` 各加 `gx-root`（抬到 z=2）。

玻璃段共 **37 条规则**（`html.gx-glass` 在选择器里出现 49 次、逗号展开后是 47 个选择器；基线一共 61 条规则），四类：

| 类别 | 做法 |
|---|---|
| 表面 | `.card` / `.col.today` / `.day` / `.day.today` / `.day.sel` → `background: transparent`，边用 `var(--theme-border)` |
| 需要垫底的三处 | `header` = `rgba(var(--veil-rgb),.42)` + `blur(6px)`；`.week-head` = `.80`（它是 `position:sticky`）；页签/按钮/`.titem` 用白色 **≤ .06** 的一层皮 |
| 字色 | 一律走公共层 token：`--theme-fg` / `--theme-fg2` / `--theme-muted-fg` / `--theme-primary`，**一个 hex 都不写死**（I9 钉"引用的 token 必须在 `glass.css` 的 `.tk-rain` 里存在"） |
| 三条色块 | 亮色低饱和填充 + 亮字，数值与学生页 `.evt.*` 同一档（`.14/.42`），两页看着是一套东西 |

内联样式那几处（`#ttConfirm`、图例三个 `<i style="background:#eaf1ff">`）类规则压不动，只能用 `!important` —— 与学生页 `LEAK` 那条同一招。
