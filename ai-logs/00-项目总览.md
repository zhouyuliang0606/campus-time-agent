# ai-log 00 · 项目总览（我们做到了哪一步）

> 这是「校园时间管家 Agent / CampusTime」的开发日记第 0 篇：把到目前为止的对话和决策整理清楚，方便评审和后来的自己回看。

## 一、我们要做一个什么
一个**校园 AI 服务助手**，分三层：
1. **学生活端（旗舰）**：课表时间规划 + 校园问答，把分散的校园信息收口到一个助手。
2. **驿站/商户侧**：监听快递外卖台账变动，主动推送取件提醒与滞留预警，用自定义人格智能回复咨询。
3. **管理控制台**：零代码维护知识库、配置客服人格。

三层**共用一个 Agent 引擎（意图路由 + 协调执行）+ 知识库 + 大模型**。

## 二、技术选型（为什么这么选）
| 选型 | 原因（大白话） |
| --- | --- |
| Python + FastAPI | 后端简单清晰，接口一行就声明好，新手也能看懂 |
| 原生 HTML/JS 前端 | 不引入打包工具，双击就能看，评委环境零依赖 |
| DeepSeek API | 便宜、中文好、兼容 OpenAI 格式；Key 走环境变量，不进代码 |
| 自写轻量 ReAct | 不套 LangChain 等重框架，循环逻辑透明，评委一眼看懂"Agent 怎么想" |

## 四、怎么本地跑起来（零基础版）
1. 装依赖：`pip install -r requirements.txt`
2. 复制 `.env.example` 为 `.env`，填入你的 DeepSeek Key
3. 启动：`uvicorn app.main:app --reload`
4. 浏览器打开 `http://127.0.0.1:8000`
