# 22 · 不需要先问，直接敲定：第一站从「二选一卡」改成「单条确认条」

> 学生发来一张截图 + 一句明确指令：
> 截图：「帮我安排出去吃饭的时间」→ 管家反问「把想安排的**时间和日期**说一下吧……」
> 指令原话：「**改一下逻辑，不需要先问，直接去安排，重复的确认太麻烦，直接敲定结果，主打效率**」
>
> 这是「只说了哪天/什么都没说」这一档的**第四次**改版（前三版都记在第五批和第十批的
> docstring 里）。学生每次表态都把整条链路掰一次，这次也一样——四版全史如下。

## 一、规格沿革（四版全史）

| 版本 | 第一站 | 为什么改 |
| --- | --- | --- |
| 一 | 系统替他挑一个点 | 被驳回：「我定的太严了」——要能列举、由他打勾 |
| 二 | 摊开几段候选 | 又被驳回：「要区分两种……不要一上来就询问详细时间，先给弹窗」 |
| 三 | **二选一卡**（你自己定 / 我帮你挑） | 用了一阵，学生嫌这一轮问答多余 |
| 四（本次） | **系统直接敲定一段，出单条确认条** | 「不需要先问，直接去安排……主打效率」 |

细读四版会发现学生嫌的从来不是"替我挑"，而是"**先问我一轮**"。
四版共有的铁律一直没动：**不反问"几点到几点"、写库必须他点头、绝不硬凑时间**。

## 二、这次截图其实叠着两个问题

**① 识别**（跟 `ai-logs/21` 同族）：「帮我安排出去吃饭的时间」——
`_strip_title_noise` 只擦**开头**的"时间"，没擦**结尾**的「的时间」；
`_TITLE_NOISE` 里的"时间"于是把「出去吃饭**的时间**」整句否掉 → 追问"要安排的是什么事"
→ 又因为这句是模型口吻（不在代码里），说明请求一路漏到了模型。

修法一行：结尾清理加上"时间"（只剥**结尾**，「时间管理」这种中间的不动）：

```python
t = re.sub(r"(的)?(待办|代办|事项|日程|时间)$", "", t).strip("的")[:30]
```

**② 规格**：3c 分支不再把二选一卡递出去。`todo_mode_proposal` 照旧算
（它里头的标题判真和时长解析丢不得），但就地走"你帮我挑"那条路：

```python
mode_card = todo_mode_proposal(blob)
if mode_card is not None:
    picked = mode_to_card(mode_card, "ai")     # 系统挑一段，出单条
    if picked is not None:
        return _offer_response(..., "⚡ 学生没定时间 → 系统直接敲定一段")
    slots = mode_to_card(mode_card, "self")    # 挑不出（都排满）→ 退候选卡
    if slots is not None:
        return _offer_response(..., "🙋 直接敲定失败 → 摊出候选时段")
# 连事名都判不出 → 才追问"要安排什么事"
```

每一级都比上一级多问一句，**能不问就不问**。
`/api/todos/mode` 接口、mode 卡类型、前端按钮**全部保留**——旧会话/模型那一路
还会出二选一卡，那条契约没断。

## 三、话术只承诺系统能兑现的事

第一版文案写的是「或者『换一天』，我马上重排」——写完自查发现：
**"换一天"没有分支接**（`retime` 只认带钟点的"改成X点X点"，"改成周六"倒是认）。
文案承诺了系统兑现不了的事，就是 `ai-logs/18` 以来的老毛病换了个温和的形态。
收回来，改成「说一句『改成周四晚上七点到八点』这样的话」——这句 `retime` 认。

## 四、断言跟着规格走（第五/八/九/十批）

三处端到端场景从"先出二选一卡"改写成"直接敲定"，改法各有门道：

- **第五批 ③**：`帮我安排周二的游泳` → 直接出单条（auto 卡、date=周二、话里带理由）；
  "我自己定"那轮删除，后半段"报新点就换"（3c-pre 换时间）原样保留。
- **第八批 ④⑥**：同款改写；⑥ 里「你帮我挑」一步删除（暂存里现在是单条卡，
  说"改成周六"直接走换天）。
- **第九批 ⑤⑥**：候选卡退居两处（直接敲定失败、模型那一路），
  聊天链路不再天然产生它——所以这两处改成**把卡种进暂存**
  （`_remember_todo_options`）再测，batch 落库/重复拦截/其他自填/400 那些
  接口级断言一条没少。
- **第十批 ⑥⑦⑧⑨**：⑥⑦⑧ 改成"第一轮即单条 → 回确认落库"；
  ⑨ 的 mode 接口同样改为种卡再调。

**教训**：规格变更时先数清"这条链路的入口在哪几个批里被钉着"——
这次入口同时存在于第五、八、九、十批，漏一处就红一处。
`grep` 断言文案里的关键词（"二选一"/"我自己定"）比翻代码快。
