## 一、录之前先过这六条（缺一条就别开录）

1. **服务**：`python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`，浏览器开 `http://127.0.0.1:8000`。
   ⚠️ **别加 `--reload`**（中文 Windows 上它会把重载器拖进 GBK 坑，README §五 写了原因）。
2. **两个学号**：`admin1`、`admin2`。名录里只有这两个，别的学号 403；**只填学号、没有密码**。
3. **管理口令**：`.env` 里那串（文档里不写值），只在管理端顶栏输一次；它存 `sessionStorage`，关标签就清。
4. **模型 Key**：管理端「API 配置」显示配好了再录。**没 Key 也能录**，但镜 2、镜 6 的答法会换成离线那一句
   （每镜下面标了"离线那行"），别到镜头前才发现两者不一样。**镜 6 没 Key 直接演不了**。
5. **两份料**（都在仓库里，评委 clone 就有）：
   `docs/演示料/校园知识手册.txt` —— 924 字，实测切成 **2 块**；
   `docs/演示料/秋季课表.csv` —— **7 门课**，csv 与 docx 走同一条"读文件→提案→确认"链路。
6. **数据摆位**：`admin1` 有课表 + 一份知识文档（镜 2、镜 3 用），`admin2` 留空库（镜 1 演"新学生"）。
   先在副本上照本分镜走一遍，再到真机上重放 —— **别拿真机当第一次试验场**。

## 二、主线七镜（合计约 6'40"）

### 镜 1 · 新学生：一句不写，先让他传课表（0:00–1:20）

- 画面：登录页 →【我是学生】→ 输 `admin2` →【进入】。顶栏出现「**👤 admin2**」+「退出登录」。
- 屏幕该出现（实测原文）：逐日明细那一格写着
  > 还没有课表。点上面的【上传课表】传一份（docx / xlsx / pdf / txt / csv 都行），我读出清单、你确认之后才写进周表 —— 在那之前这边一条数据都不会有。
  > 没有文件也可以直接跟我说，例如「周一 08:00-09:40 高等数学 教三301」，我照样能记进周表。
- 点【上传课表】选 `docs/演示料/秋季课表.csv` → 气泡自己发一句「📤 上传课表《秋季课表.csv》，请管家读取并给我预览清单」
  → 几秒后：「📄 课表读好了，共 **7 门课**。要不要用这份课表替换现在的周表？ 点卡片上的【确认修改】才写入；不想改就点【取消】，周表一个字都不会动。」
- 那张卡**不是全屏弹窗**，是贴在聊天流里的一条 —— 它的 UI 是独立页面 `/confirm?session=…`（能单独打开、单独验收，这也是本项目的一个卖点）。
- 点【确认修改】→「✅ 已经按你的确认改好了，日程已刷新。」→ `GET /api/timetable` 实测 7 门课。
- 接口链：`POST /api/upload` → `POST /api/chat`（卡 `kind=timetable_change`）→ `POST /api/timetable/apply` → `GET /api/timetable`。
- 钉它的测试：`test_23_timetable_import_rescue.py`、`test_26_upload_card_channel.py`、`test_29_schedule_panel_and_todo_api.py`。
- ⚠️ 两个坑：① 默认只列**今天起 4 天**，周一的课要按【展开整周 ▾】或 ←/→ 翻周才看得见；
  ② 这一镜**别点开**「🧠 我是这么想的」—— 里面写着「我把这句听成 **问事**」，而它其实办了事（措辞待修，见 §七）。

### 镜 2 · 问答抽屉：只答查得到的，查不到就说查不到（1:20–2:30）

- 先在管理端「文档知识库」传 `docs/演示料/校园知识手册.txt` → 列表一行：924 字 / **2 块** / 索引「已建」。
- 用 `admin1`，点日程面板那颗「**❓ 校园问答**」→ 抽屉是一排按钮墙（实测 10 条：图书馆几点关门？校车在哪坐、几点发车？教务系统网址…）。
- 点「校车在哪坐、几点发车？」→ 实测 **3.2s**（流式出字），气泡原文：
  > 我查了知识库，校车的信息在《校园知识手册》的「二、校车」这一节里，但**手册里只写了线路和班次，没有写具体在哪个站台、哪个门口上车**，所以上车点我这边确实查不到，建议问一下后勤或校车管理处，或者看校车上的线路牌。
  > 手册里能确认的是这些：线路 / 班次 / 首末班（首班 06:30 从闸北发出，末班 21:00 从松江发出）/ 乘车凭证…
  > 小提示：**今天周三**属于工作日，按高峰、平峰的时刻表走；周末出门记得班次会减半…
- **这是全片最值钱的一句解说**：它引用的确实是被检索到的块，而手册没写的那半句它**当场承认查不到**，没编一个站台出来。
- 接口：`POST /api/chat`（faq 那一路 = 问答条目 + 上传文档**一次查全**）。
- 钉它的测试：`test_66_doc_chunks.py`、`test_67_kb_docs_merged.py`、`test_68_demo_polish.py`、`test_15_oral_samples.py`。
- 换人对照（同一句话，另一个人答不出）：退出登录 → `admin2` → 问同一句 → 实测 4.9s
  「…都没有找到松江校区校车时刻的相关内容，所以这个我暂不清楚，不能瞎给你一个时间」。
  一句台词就把 #45 的"每人一库"演完了，不用讲第二段道理（admin2 那边 `GET /api/uploads` 实测 `{"files":[]}`）。
- 离线那行：没 Key 时走"知识库直答"，念的是块里的原文，**不会**有末尾那句"小提示"。

### 镜 3 · 一段材料 → 三条待办 → 点确认才写库（2:30–3:35）

- 点输入区「**粘贴文本**」→ 粘下面三行 + 一句「帮我把这段通知里的安排都加进日程」→【发送】：
  `10月23日 14:00-15:00 计算机2501班 身高体重`／`10月24日 14:00-15:00 计算机2502班 肺活量`／`10月25日 09:00-10:00 软件2501班 立定跳远`
- 实测 **747ms**（没走模型）：卡片是 **3 个勾选框、全部预勾上** + 一颗「✅ 加入日程」，气泡写着
  「📋 这段材料里我提出 **3 条**要排的事（只按这段材料本身，没结合上文，也没补材料里没有的信息）：…」
- 点【✅ 加入日程】→「⏳ 正在写入…」→ 回执逐条带日期与周几；同时周五那行出现「08:00-09:40 线性代数 · 教三301」**和**「14:00-15:00 计算机2501班身高体重」—— 课与待办同屏。
- 接口链：`POST /api/chat`（卡 `kind=todo_add_batch`）→ `POST /api/todos/items_add`。
- 钉它的测试：`test_71_material_batch.py`、`test_12_batch_todo.py`、`test_36_pending_card_restore.py`、`test_60_card_close.py`。
- ⚠️ **别拿左栏「代办事项」那个角标当证据**：`updateTodoBadge` 只数**今天**的待办（实测写完三条，角标仍是 1 —— 这是对的，不是 bug）。
  证据用回执气泡 + 周五那一行。

### 镜 4 · 一句话一条事：钟点用他点的，表达不了的周期不假装（3:35–4:25）

- 「**明天下午三点到五点打羽毛球**」→ 实测 710ms → 卡「📝 要不要把 **打羽毛球** 排进日程？2026-10-22（周四）15:00-17:00」→【确认加入】。
  随后 `GET /api/pending/<sid>` 实测变 `null` —— **写完当场销卡**（F5 不会再弹第二张、不会多写一条）。
- 「**以后每天晨跑**」→ 实测 857ms → 卡「🔁 **每天** · **晨跑**」+ 摊几个空档让他勾（周四 19:00-20:30…）。
  解说：一条日程表达不了"每天"，它**不假装建成一条**，而是把能办的两种说法摆出来。
- 钉它的测试：`test_06_add_things.py`、`test_40_time_spec.py`、`test_42_period_veto_and_title_carry.py`、`test_36_pending_card_restore.py`。
- ⚠️ **这两句当场实测会翻车，别演**：
  「明天下午三点打羽毛球**两小时**」→ 时长不生效，仍是 15:00-16:00；
  「明天下午三点打羽毛球，**两个半小时**」→ 事名被抠成「打羽毛球**两个**」。要报时长就说"三点到五点"。

### 镜 5 · 报障 → 工单 → 驿站改状态 → 自动归档（4:25–5:15）

- 「**我的外卖丢了**」→ 实测 1005ms → 卡「📮 听起来你的快递/外卖可能出了问题。要不要**上报驿站**立案跟进？…」，`wo_kind=外卖丢失`。
- 点【确认上报】→ `POST /api/workorders` → 学生端 `GET /api/my/workorders` 有这一条；管理端 `GET /api/workorders`（挂口令）读到**同一份**（双写，不是各记一遍）。
- 切 `/station`：工单在待处理 → 改「已解决」→ **自动归档**，「🗄 已处理 N 条」里能展开、能放回。
- 钉它的测试：`test_27_express_lost_report_card.py`、`test_51_report_dual_write.py`、`test_52_station_workorders.py`、`test_63_my_workorders.py`、`test_58_ledger_archive.py`。
- ⚠️ **别换成设施报修那句**：「游泳馆更衣室的柜子坏了」实测走成 faq（答"手册里没这条"），**不出工单**。
  这族硬信号词是 快递 / 外卖 / 丢失 / 破损 / 上报 / 工单；想演"柜子坏了"就走下一镜的自建服务。

### 镜 6 · 低代码：驿站一句话加一项服务，学生的话当场命中它（5:15–6:05）

- 建服务：`POST /api/station/services {"description":"加个失物招领，登记丢的东西和大概在哪丢的"}` → 200，**立刻**出现在服务列表。
  内置那项 `pkgloss/快递/外卖问题处理` **删不掉**（实测 400）；**重名会被拒**（实测 400：「已经有一个叫「失物招领」的服务了，换个名字或先删掉它」）—— 要演就换个名字。
- 学生说「**我丢了饭卡**」→ 实测 2.7s → 卡 `kind=custom_record`，**字段已经替他填了一个**：物品描述=饭卡，丢失地点/大概时间/联系方式 空着等他补。
- 点【确认】→ `POST /api/custom/records` → 驿站端那条登记出现 → 可改状态（待处理 / 处理中 / 已解决）。
- 钉它的测试：`test_53_lowcode_service.py`、`test_54_custom_service_intent.py`。
- ⚠️ **干净 clone 上没有自建服务**，这句会走 faq 答一段挂失补办流程、**不出卡** ⇒ 顺序必须"先建服务，再说那句话"。

### 镜 7 · 一段代码与一张表（6:05–6:40）

## 三、镜 8 · 护栏与「AI 协同过程」（6:40–7:30）—— 这是评分重点

- 终端跑 `python tests/run_all.py`，屏幕停在它**真跑出来的那些行**：逐批「通过 X 项，失败 Y 项」+ 末尾总账 + 一个 echo 退出码。
- **不承诺零失败，也别把它剪成"全绿"**：口播念"这一轮我本机跑出来是〈当场念〉"。
  有红就照实念一句归因（红项归因一向记在当轮快照与接手指南 §六），**别剪掉**。
- 判"有没有红"要念**两行**：总账那句 + 下面的 `有失败的文件：…`。某份文件整份 import 崩时，总账算不出"失败几项"，只有这一行露头。
- 录到 AI 助手的**真实对话界面**（旧版写的 WorkBuddy 就是这一档，工具换了、要求没换）：
  给一段"人说 → AI 读码研判 → AI 出方案"的来回，再切 `ai-prompts/` 里对应那份快照。
- 同屏再开两样：`git log --oneline | wc -l`、一份快照与**它自己的 commit** 并排
  （例如 `git show --stat a27d943` ↔ `ai-prompts/2026-10-21-kb-entry-table-committed.md` §二）。
- 主线一句（评委要听的）：**施工单是 AI 写的、断言是 AI 跑的、前提被实测推翻的时候它留了两份证据**（红项 + 归因），
  而不是把被推翻的那句悄悄改掉。
- ⚠️ 别说"每个演示动作都有一条测试兜着" —— 除非你真按本文件那张映射表逐条 `grep` 过。
  **文件名对得上不等于断言钉的是这一镜**（本项目吃过好几次"断言钉错对象"的亏）；
  录前用 `grep -n "<屏幕上那句原话>" tests/test_XX.py` 当场核一遍再念。

（参考账，会过期，以当场为准：截至 `90ff758`，本机与严格克隆同为 4354 项 / 0 失败 / 73 批。）

## 五、界面实测备忘（省得录的时候猜文案）

- 登录页：三张身份卡（学生 / 管理员 / 驿站），底下一行小字
  「演示用：学生只填学号、不设密码（这不是鉴权，只是把每个人的课表待办分开）」—— 这句值得念一遍，比事后被评委问住强。
- ⚠️ 学号输入框 placeholder 是「**如 S001**」，而名录里只有 `admin1/admin2`。看着不一致；录时直接输 `admin1`，要不要改 placeholder 归口径拍板（§七）。
- 顶栏：「👤 admin2」「退出登录」「完整日程」。左栏：日程 / 校园通知 / 代办事项（角标=今天） / 设置 / 更多服务 ▾。
- 日程面板按钮顺序：周视图 | 月表 | ❓校园问答 | 展开整周 ▾ | 上传课表 | ← →；下面一行「2026-10-21 ~ 2026-10-24（今天起 4 天）」。
- 输入区一圈：粘贴文本 / 意图诊断 / 上传资料给管家读 / 语音输入（中文）/ 清空聊天记录，加「模型与 API」下拉（默认显示"默认模型（管理端配置）"）。
- **耗时实测**（心里有数，卡三秒不是坏了）：确定性分支 0.7–1.0s；带模型的问答 / 低代码 2.7–6.3s；管理端列表与【试查】10–40ms。

### 可选镜（评委追问"管理员怎么知道学生问得到吗"时用，+40s）

- 管理端「知识库」加一条：问题 / 答案 / **关键词留空** → 存进去实测 `keywords=["健身房价格"]`（从问题里自动提的词）。
- 【试查】输「健身房多少钱」→ 实测 **11ms**，屏上
  「✅ 查到了｜问答条目：0. 健身房价格｜文档块：没命中｜学生在气泡里会看到：问：健身房价格 答：一个月159，单次30」。
  清空输一句 → 400「先写一句要试查的话」（不许"成功地查到 0 条"跟真查不到长得一模一样）。
- 解说：探针调的就是学生那**同一个函数**，所以这里查到 = 学生查得到，不是另写一套自证。
- ⚠️ 两处已知丑，提前知道别当场愣住：① 单个 5 字的问题提不出更短的词片，提到的就是**整串**「健身房价格」，想好看就手填「健身房」；
  ② 探针那段"学生会看到"会把下一节标题（「三、游泳馆」）一起带出来。
- 若列表读不到，面板现在写的是「知识库列表读不到：…（点【刷新列表】重试，或检查管理口令）」——
  出现这句是**口令没填对**，不是知识库空了（这句本身就是 #46 修的"读失败长得像空库"那个 bug，很值得在视频里点一句）。

## 六、录制与导出

- OBS 或 Win+G；**1920×1080 / 30fps / H.264**，成片 5–8 分钟；含字幕或清晰口播，音量正常无杂音。
- 浏览器 Ctrl+ 放大一档，收起书签栏和扩展图标；鼠标别跳，输入前把光标停在输入框半秒。
