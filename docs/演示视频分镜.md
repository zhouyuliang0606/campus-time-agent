# 演示视频逐镜脚本（5–8 分钟，MP4 / 1080p）

> 用途：提交「AI 创新应用挑战赛」演示视频。沙箱无法录屏，请在你本地用 OBS /  Win+G 录屏，
> 按本脚本分镜录制。**硬性要求：必须含「AI 协同过程复现展示」**——所以第 3 镜务必录到
> WorkBuddy（AI 助手）的真实对话界面，不能只录产品本身。

## 录制环境
- 分辨率 1920×1080，帧率 30fps，麦克风录解说（或后期配音）。
- 浏览器开 `http://127.0.0.1:8000`（先 `uvicorn app.main:app --reload`）。
- 竖屏/横屏均可，但全程 1080p；字幕或口播讲清每一步。

---

## 分镜（总时长目标 ≈ 6 分 30 秒）

### 镜 1 · 开场 + 提交清单（0:00–0:40，约 40s）
- 画面：先给仓库页 `github.com/zhouyuliang0606/campus-time-agent`，再切终端 `git log --oneline | head -20`，
  最后切项目首页截图。
- 解说：「这是一个校园 AI 助手『校园时间管家』。本视频对应比赛提交清单：Public 代码仓库、115 个细粒度 Git 提交、
  AI 对话 Prompt 快照、README 复现指南、技术文档 PDF，以及这份演示。下面我边做边展示 AI 是怎么跟我协同开发的。」

### 镜 2 · 架构一句话（0:40–1:30，约 50s）
- 画面：打开 `app/main.py` 的 `/api/chat` 或技术文档第 3 节架构图；可画个简单示意图。
- 解说：「核心设计是 Propose/Execute 分离：AI 只出提案，学生点确认才写库；弹窗显示由系统盖的 kind 标记驱动，
  不是模型说了算。所以『不弹弹窗』的根因，是某句话没被确定性分支接住、掉进了模型。」

### 镜 3 · AI 协同过程复现【必录 WorkBuddy 界面】（1:30–2:30，约 60s）
- 画面：**完整录下 WorkBuddy 对话**：用户发「先修弹窗不出现，你有什么想法」→ AI 读 `/api/chat` 代码、
  给出研判（确定性分支已在模型前做意图分析、提案由系统盖 kind）→ 列出三类待办口语缺口。
- 解说：「这就是 AI 协同：我给一句 Prompt，AI 先去读码研判、再给方案，而不是瞎编。每一步结论都能在代码里核对。」
- ⚠️ 此镜是评分重点，务必让观众看到「人说 → AI 读代码 → AI 出方案」的真实来回。

### 镜 4 · 产品实机演示（2:30–4:00，约 90s）
- 画面：浏览器操作，三句话连测——
  1. 输入「帮我把今天的『复习线性代数』安排到 19:00 到 20:30」→ 出现**确认弹窗** → 点【确认加入】→ 日程格子出现该条。
  2. 输入「我的代办呢」→ 系统**列出已有待办**（证明是系统真查库，不是编的）。
  3. 输入「代办显示不出来」→ 系统把待办念出来（覆盖整张列表看不见的场景）。
- 解说：「注意第二、第三步——同样是『看我的待办』，系统是真查库念出来，不是模型凭空编『你有 3 条』。」

### 镜 5 · 测试护栏（4:00–5:00，约 60s）
- 画面：终端 `python tests/run_all.py`，停在「总账：通过 905 项，失败 0 项（共 7 批）全部通过 ✅」。
- 解说：「所有改动都有自动化护栏。新增的待办口语测试 19 项、全量 905 项全绿，证明弹窗链路没有被改坏。」

### 镜 6 · Prompt 快照对照（5:00–6:30，约 90s）
- 画面：打开 `ai-prompts/2026-09-25-todo-gaps.md`，滚动展示「用户 Prompt → AI 研判 → 改动 → 验证」；
  再切终端 `git show --stat 0f4852a` 和两份快照提交 `eee76c9 / 041af38`。
- 解说：「每次开发会话都有一份 Prompt 快照随代码提交。把这份快照和它的 commit 对照，评审就能还原那一步的协同过程——
  这就是『细粒度提交 + AI 对话快照』要求的交付方式。」

### 镜 7 · 结尾（6:30–7:00，约 30s）
- 画面：回到仓库页 + README 顶部。
- 解说：「仓库 Public、历史完整、快照齐全、文档与视频齐备。校园时间管家，AI 协同开发成果，提交完毕。」

## 解说词要点（避免踩雷）
- 反复点题：**「AI 读代码研判 → 系统出提案 → 人确认才写库」**，这是全程主线。
- 凡提到「已经加上/已经删了」，都要补一句「是系统在点确认后真实写入，不是模型嘴上说」。
- 第 3 镜若 WorkBuddy 对话太长，可剪到 60s 内，但必须保留「人 Prompt → AI 读码 → AI 方案」三段。

## 成片要求
- 格式 MP4，H.264，1080p，5–8 分钟。
- 含字幕或清晰口播；音量正常，无杂音。
- 文件名建议：`CampusTime-演示-2026-09-25.mp4`，随仓库或按赛道入口上传。
